# vaultwarden_infrastructure
This project deploys Vaultwarden — an unofficial Bitwarden-compatible server — on Kubernetes.

## Prerequisites
- k3s / any local Kubernetes cluster (in the first iteration this project deploys manually)
- kubectl
- Docker


## Current State / Roadmap
✅ Stage 1: Local k8s deployment (k3s)

⬜ Stage 2: CI/CD pipeline (GitHub Actions)

⬜ Stage 3: Monitoring (Prometheus + Grafana)

⬜ Stage 4: AWS deployment
